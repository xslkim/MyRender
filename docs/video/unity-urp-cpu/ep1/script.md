有三件事必须和它**一模一样**
第一是坐标系
左手系、Y 朝上、Z 朝前、单位是米
第二是矩阵约定
行列主序、乘法顺序、投影的 NDC 范围
第三是光照单位
光强怎么算、在线性还是 sRGB 空间、BRDF 怎么归一化
这三处只要错一点
对照就没意义了
所以导出时把这些约定全部写死
