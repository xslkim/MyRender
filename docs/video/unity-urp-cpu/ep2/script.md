--- narration ---
渲染时算出来的亮度
范围可以很大
远超屏幕能显示的 0 到 1
如果直接截断
亮的地方就会一片死白
所以要做 **色调映射**
用一条平滑的 S 曲线
把过亮的部分柔和地压回可显示范围
亮处保留层次
这条曲线叫 ACES
是电影里常用的那一套
Unity 用它
我们也照搬
